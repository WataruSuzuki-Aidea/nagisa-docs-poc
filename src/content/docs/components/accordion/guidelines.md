## 使い方

### 使うと良いケース 👍

- 見出しで区切れる複数のセクションがある
- すべてのコンテンツを一度に表示すると長くなり、必要なセクションだけを開いて見たい
- 利用者がセクションを選んで読む（すべてを順に読む必要がない）

#### 利用例

| 分類 | 事例 |
| --- | --- |
| 設定 | 設定画面<br>・通知 / 表示単位 / 言語とタイムゾーン… |
| 一覧の詳細 | 航海の一覧<br>・航海ごとに、出港・船長などの詳細を開く |
| ダッシュボード | 船舶の状態<br>・燃料 / 機関 / 気象… |
| FAQ | ヘルプ<br>・よくある質問と回答 |
| 手順 | 初期設定<br>・手順を1つずつ開いて進める |

### 使わない方が良いケース 🤔

| ケース | 代替のコンポーネント |
| --- | --- |
| 開閉する領域が1つだけ | ・Collapsible |
| 同じ階層の複数のコンテンツを切り替え、常にどれか1つを表示したい | ・Tabs |
| 階層データをツリーで一覧・選択したい | ・専用のコンポーネントを作成予定 |
| サイドバーのメニューのグループを開閉したい | ・Sidebar |
| すべてのコンテンツを常に見比べる必要がある | ・区切り線や見出しで並べて表示する（開閉しない） |

★現時点ではDataGridは独自のものを使うケースを想定

## Do ✅ / Don't ❌

### スタイル（色/形状）

#### Do ✅

- 迷ったら divided を使います。
- カードやパネルの中に置く場合は、枠が二重にならないよう divided か plain を使います。contained は、カードの外側で1つのまとまりとして見せる場合に使います。
- separated は、項目が少なく（5個以下が目安）、それぞれが独立したコンテンツの場合に使います。
- plain は、周囲の余白やレイアウトで項目の区切りが明らかな場合に限ります。

### ライティング

#### Do ✅

- タイトルは、セクションを表す名詞で書き、開閉に合わせて文言を変えません。並べたときに、対象範囲の粒度や表現を揃えます（例：「通知」「表示単位」「言語とタイムゾーン」）。
- 項目を見分けられる固有の情報を、タイトルの先頭に置きます（例：「V-2026-0412 横浜 → シンガポール」）。
- FAQ では質問形のタイトルも使えます。1〜2行に収めます（例：「燃料消費量はどのように計算されますか？」）。
- 項目を無効にする場合は、理由を伝えます（例：「データの保存期間（管理者のみ変更できます）」）。

### 先頭側項目、末尾側項目

#### Do ✅

- 先頭側には、セクションの種類や対象を示すアイコン・アバターを1つ置くことを基本にします。
- 末尾側には、件数やステータスのバッジを置きます。2〜3個程度までにします（例：「未対応 3件」「運航中」）。
- ステータスは、バッジなど文字で示すことを基本にします。アイコンだけで示す場合は、ツールチップで意味を補います（例：警告のアイコンに「要確認」）。
- 同じアコーディオンの中では、先頭側項目の有無と種類を項目間で揃えます。

#### Don't ❌

- 先頭側・末尾側項目に、ボタンやリンクなど操作できる要素を置かないでください。見出しのボタンの中に入れ子にできず、キーボードやスクリーンリーダーで操作できなくなります。

### アクション

#### Do ✅

- ボタンやリンクなど操作できる要素は、アクション（actions）に配置します。末尾側項目には、操作できない補足（バッジ、状態のアイコンなど）だけを配置します。
- アクションは1〜2個までにします。それ以上の操作は Dropdown Menu（「…」のメニュー）にまとめます。
- 削除などの取り消せない操作は、確認のダイアログを表示します。
- アクションのボタンは、何に対する操作かがわかる名前にします（例：アイコンのみのボタンに「通知を編集」）。

### サイズとレイアウト

#### Do ✅

- タッチ操作が中心の画面では md を使います。

#### Don't ❌

- 項目の中にアコーディオンを入れ子にしないでください。階層が深くなり、見出し構造と操作がわかりにくくなります。

### インタラクション

#### Do ✅

- 項目を1つずつ順に見せたい場合（手順など）は、type を single にします。複数を見比べる用途では multiple（既定）のままにします。

### アクセシビリティ

#### Do ✅

- 見出しレベル（headingLevel）は、ページの見出し構造に合わせて指定します（既定は3）。
