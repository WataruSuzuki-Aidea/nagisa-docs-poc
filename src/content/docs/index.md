## NAGI(SA)とは

Aideaの製品やサービスを提供する画面を作る上で、効率よく、品質の高い成果物を開発するために、デザインする上での考え方、使用する部品、作り方、ワークフローを包括的に提供することを目的にしています。言うなれば、誰でも組み立てできる、取り扱い説明書付きのAideaデザインパッケージです。

## NAGI(SA)デザインシステムの位置付け

デザインシステムを利用して作成する画面は大きく分けると2種類あると考えられます。

### 標準化された基本的な画面

アプリケーションには標準化され汎用的に使える画面があります。入力ページ、一覧ページ、コンテンツメニュー、お知らせメッセージなどがそれに当たります。このような画面が必要になった時に、毎回同じものを最初から作らなくていいように、デザインシステムは基本的な画面を作る部品（コンポーネント、ウィジェット、モジュール、ページテンプレート）を提供します。これらのページを作成するのに必要以上の労力と時間をかけることはありません。デザインシスムを活用して効率的にアウトプットしましょう。

### Aideaの製品、サービス特有な画面

海図やカメラ、船舶動静、船舶、船員、工程管理など少し特殊な用途や専門的な業務に使われる画面もあります。このような画面に対しても、今までのAideaの成果物や蓄積されたナレッジを元に、必要なスタイルやコンポーネントなどを提供します。これをベースとして必要なカスタマイズを施し、各要件を満たす画面を作成してください。

## デザインシステム全体のリソース構成

下記で構成されています。

| リソース | ツール | 説明 |
| --- | --- | --- |
| ソースコード | GitHub | コンポーネント・ウィジェット・モジュール（UI要素）のソースコードです |
| カタログ | Storybook | UI要素のインタラクションやAPIなどを確認します |
| ドキュメント＋トークン出力 | Supernova | デザイン全般の方針やルール、デザイントークンやUI要素の利用方法などを記載します |
| デザイン用ライブラリ | Figma | UI要素実装の参照元となるFigmaのデザイン用ライブラリです。 |
